# こつこつ家計簿

日本語・日本円の家計簿。収入・支出の登録と編集、月別集計、カテゴリー別内訳、予算と残額表示、履歴検索、削除確認、JSONバックアップと復元、Excel向けCSV出力に対応しています。

## Windowsで使う

`dist/家計簿.html` が単体で動く版です。EdgeやChromeで開きます。PythonやNode.js、インターネット接続は利用時には不要です。ブラウザによりファイルの保存領域が異なるため、同じファイルパスとブラウザで使用してください。ファイルの移動・更新前には「バックアップ保存」を行い、必要なら移動先で復元してください。

データはブラウザのlocalStorageに保存します。端末間同期・アカウント機能はありません。ブラウザのデータを削除すると記録も消えます。バックアップには全期間の記録と月別予算が含まれ、復元は確認後に全件を置き換えます。以前のWindows版のバックアップ（JSON配列）も復元できます。CSVは表示月の全記録を出力し、検索条件には影響されません。

## 開発

Node.js 24、配信用にPython 3を使用。開発依存パッケージの導入は不要です。

```sh
npm test
npm run build
npm start
```

`npm run build` は `dist/家計簿.html` を生成します。`npm start` はポート3000で開発用ファイルを配信します。

自動テストは入力検証、集計、バックアップ形式、CSVの引用符と数式対策を対象にしています。画面処理は別途DOM環境で登録・編集・削除・検索・予算表示・旧版データ読み込み・単体HTML実行を確認しています。実際のWindows/Edgeでの見た目とダウンロード操作は未検証です。
